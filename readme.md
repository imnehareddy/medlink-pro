# MedLink Pro 🏥

## Full Stack Healthcare & Appointment Management System

MedLink Pro is a professional full stack healthcare web application developed using PHP, MySQL, HTML, CSS, JavaScript, AJAX, and Chart.js.  
The platform enables patients to book appointments, doctors to manage appointments, and admins to monitor the entire healthcare system through analytics dashboards.
