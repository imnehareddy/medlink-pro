# MedLink Pro 🏥

A Full Stack Healthcare & Appointment Management System.

## Features

- Multi-role Authentication
- OTP Verification
- Patient Dashboard
- Doctor Dashboard
- Appointment Booking
- Prescription System
- Upload Medical Reports
- AJAX Doctor Search
- Analytics Dashboard
- Chart.js Graphs
- Admin Panel

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- AJAX
- Chart.js
- XAMPP

## Modules

### Patient
- Register/Login
- Search Doctors
- Book Appointments
- Upload Reports

### Doctor
- Manage Appointments
- Approve/Reject
- Add Prescriptions

### Admin
- Manage Doctors
- Manage Patients
- Analytics Dashboard
